# Security policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch. Published
release support is announced in each GitHub Release.

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue. Use GitHub's private
security-advisory reporting flow for this repository:

https://github.com/WAsbry/NextThing/security/advisories/new

Include a minimal reproduction, affected version/commit, impact, and suggested
mitigation. Do not include API keys, access tokens, personal task data, precise
location history, private model files, or unredacted logs.
