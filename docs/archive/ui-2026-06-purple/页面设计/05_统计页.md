# 05 — 统计页

## 定位

统计页展示用户的任务完成情况和习惯数据，帮助用户了解自己的效率模式。后期集成 AI 后，会加入"AI 伙伴洞察"。

## 核心功能

1. 今日 / 本周 / 本月完成率
2. 连续完成天数（streak）
3. 分类分布（饼图或环形图）
4. 每日完成趋势（折线图）
5. 成就徽章入口

## 设计要点

### 主统计卡片

| 元素 | 规格 |
|------|------|
| 背景 | Primary 渐变 → PrimaryDark |
| 文字色 | 白色 |
| 数字 | 48sp Bold |
| 进度条 | 白色半透明背景 + 白色填充 |
| 圆角 | RadiusLG |

### 小统计卡片

| 元素 | 规格 |
|------|------|
| 布局 | 2 列，间距 10dp |
| 数字 | 28sp Bold，Primary |
| 标签 | 11sp Medium，TextMuted |

### 图表卡片

| 元素 | 规格 |
|------|------|
| 背景 | BgCard，RadiusMD，ShadowSM |
| 标题 | 17sp SemiBold，TextPrimary |
| 图表 | 居中，宽度 80% |
| 分类色 | 使用分类管理中的颜色 |

## 后期愿景

1. **AI 洞察** — "你这周工作效率比上周提高了 15%"
2. **情绪趋势** — SER 数据的情绪变化曲线
3. **最佳工作时段** — AI 分析用户完成任务的时段分布
4. **习惯追踪** — 连续完成同一分类任务的 streak
