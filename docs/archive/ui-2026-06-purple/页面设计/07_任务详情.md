# 07 — 任务详情

## 定位

展示单个任务的完整信息，支持编辑所有字段。可从任务列表点击进入。

## 核心功能

1. 查看 / 编辑任务标题
2. 查看 / 编辑日期、时间
3. 查看 / 编辑分类、优先级
4. 查看 / 编辑重复规则
5. 查看 / 编辑地点
6. 添加备注
7. 删除任务
8. 标记完成

## 设计要点

与创建任务页共用配置卡片组件样式，区别：
- 导航栏标题为"任务详情"
- 右上角有删除按钮（Danger 色）
- 底部 CTA 为"标记完成"而非"保存"
- 所有字段预填充已有数据

### 标记完成动画

点击"标记完成"后：
1. 按钮变绿 + ✓ 图标
2. 标题加删除线
3. 延迟 500ms 自动返回上一页
