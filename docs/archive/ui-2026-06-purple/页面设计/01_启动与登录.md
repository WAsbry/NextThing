# 01 — 启动与登录

## 页面关系

```
启动页(Splash) → 已登录? → 今日页(Today)
                      → 未登录? → 登录页(Login) → 今日页(Today)
```

---

## 启动页 (Splash)

### 功能描述

1. 显示品牌 Logo + 应用名称
2. 申请必要权限（通知、位置）
3. 初始化 AI 引擎（ASR 模型预热）
4. 检查登录状态，自动跳转

### 视觉设计

```
┌─────────────────────────┐
│                         │
│                         │
│                         │
│         [Logo]          │  ← 应用图标，128dp
│       NextThing         │  ← 应用名称，24sp Bold
│    你的 AI 伙伴          │  ← 副标题，14sp TextSecondary
│                         │
│                         │
│      ◠ 加载中...         │  ← CircularProgressIndicator
│                         │
│   v1.0.0 · 端侧AI驱动    │  ← 底部版本号，11sp TextMuted
│                         │
└─────────────────────────┘
```

### 设计要点

| 元素 | 规格 |
|------|------|
| 背景 | BgPage 纯色 |
| Logo | 128dp，居中偏上（屏幕 35% 位置） |
| 应用名 | 24sp Bold，TextPrimary |
| 副标题 | 14sp Regular，TextSecondary |
| Loading | 20dp CircularProgressIndicator，Primary 色 |
| 版本号 | 11sp Medium，TextMuted，底部 32dp |

### 动效

- Logo 淡入（300ms）+ 轻微上浮（200ms spring）
- Loading 延迟 500ms 后出现（避免闪烁）
- 权限弹窗后如需等待，显示"正在准备你的 AI 伙伴..."

### 状态

| 状态 | 显示 |
|------|------|
| 初始化中 | Logo + Loading |
| 申请权限 | 系统弹窗 |
| 跳转中 | Loading 持续 |

---

## 登录页 (Login)

### 功能描述

1. 用户名 + 密码输入
2. 登录按钮
3. 注册入口
4. 键盘弹出时内容自动上移（已修复 Edge-to-Edge 兼容）

### 视觉设计

```
┌─────────────────────────┐
│                         │
│         [Logo]          │  ← 80dp，较启动页小
│       欢迎回来           │  ← 22sp Bold
│    登录以继续使用         │  ← 14sp TextSecondary
│                         │
│  ┌───────────────────┐  │
│  │ 👤 用户名          │  │  ← 输入框，BgInput
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │ 🔒 密码            │  │  ← 输入框，BgInput
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │      登 录         │  │  ← CTA 按钮，Primary 填充
│  └───────────────────┘  │
│                         │
│      没有账号？注册      │  ← 文字链接，Primary 色
│                         │
└─────────────────────────┘
```

### 设计要点

| 元素 | 规格 |
|------|------|
| 背景 | BgPage |
| Logo | 80dp，居中偏上 |
| 标题 | 22sp Bold，TextPrimary |
| 副标题 | 14sp Regular，TextSecondary |
| 输入框 | 高度 52dp，圆角 14dp，BgInput 背景 |
| 输入框 Focus | BorderFocus + ShadowPrimary |
| 登录按钮 | 高度 48dp，圆角 999dp，Primary + 白字 + ShadowPrimary |
| 注册链接 | 14sp，Primary 色 |
| 整体 | Column + verticalScroll + imePadding |

### 键盘适配

- 使用 `WindowInsets.ime.getBottom(density)` 手动计算键盘高度
- 作为底部 padding 添加到内容区
- 确保 Edge-to-Edge 模式下输入框不被遮挡

### 状态

| 状态 | 显示 |
|------|------|
| 空表单 | 输入框 placeholder |
| 输入中 | 输入框 focus 高亮 |
| 登录中 | 按钮变 Loading |
| 登录失败 | 输入框下方红色错误提示 |
