# 08 — 专注模式

## 定位

专注模式是 NextThing 的特色功能。结合 SER 情绪感知，AI 伙伴会在你专注时守护你，检测到分心或压力过大时给予适当提醒。

## 核心功能

1. 选择专注任务
2. 设定专注时长（番茄钟 25min / 自定义）
3. 倒计时显示
4. 背景音（白噪音 / 雨声 / 咖啡馆）
5. 专注结束提醒
6. 专注统计

## 设计要点

### 专注进行中

| 元素 | 规格 |
|------|------|
| 背景 | 深色（BgPage 深色变体） |
| 倒计时 | 48sp Bold，TextPrimary |
| 进度条 | 圆形，Primary 色，stroke 4dp |
| 任务名 | 18sp SemiBold，居中 |
| 背景音 | 小型控制条，Primary 色 |

### 全屏沉浸

- 专注模式隐藏状态栏和底部导航
- 使用深色背景减少干扰
- 倒计时数字大而清晰

## 后期愿景

1. **SER 情绪守护** — 检测到用户叹气、焦躁时，AI 温柔提醒："休息一下吧"
2. **专注报告** — 每次专注结束后生成本次专注效率评分
3. **AI 陪伴模式** — 专注时 AI 伙伴偶尔出现鼓励语
4. **声纹提醒** — 用家人声纹做结束提醒
