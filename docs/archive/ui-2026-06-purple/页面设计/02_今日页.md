# 02 — 今日页

## 定位

今日页是应用首页，用户打开 App 后看到的第一个页面。它不是简单的任务列表，而是一个**AI 伙伴视角的今日概览**。

## 核心功能

1. 显示今日问候语（结合时间 + 天气 + 用户情绪）
2. 今日任务统计（待办 / 已完成 / 连续天数）
3. 今日任务列表（按时间排序）
4. 快速创建任务入口
5. 天气主题联动（背景色随天气变化）

## 设计要点

### 问候区

| 元素 | 规格 |
|------|------|
| 问候语 | 24sp Bold，TextPrimary |
| 日期 | 14sp Regular，TextSecondary |
| 天气图标 | 跟随天气主题变化 |
| 情绪感知 | 后期集成 SER 后，问候语随情绪调整 |

问候语规则：
- 6:00-11:00 → "早上好"
- 11:00-14:00 → "中午好"
- 14:00-18:00 → "下午好"
- 18:00-22:00 → "晚上好"
- 22:00-6:00 → "夜深了，注意休息"

### 统计卡片

| 元素 | 规格 |
|------|------|
| 布局 | 3 列等宽 Row，间距 10dp |
| 卡片 | BgCard，RadiusMD，ShadowSM |
| 数字 | 28sp Bold，Primary 色 |
| 标签 | 11sp Medium，TextMuted |
| 交互 | Hover → ShadowMD + translateY(-1dp) |

### 任务卡片

| 元素 | 规格 |
|------|------|
| 布局 | BgCard，RadiusMD，ShadowSM |
| 内边距 | 14dp 16dp |
| 间距 | 10dp |
| 勾选圈 | 22dp 圆形，边框 2dp |
| 标题 | 15sp SemiBold，TextPrimary |
| 元信息 | 12sp Regular，TextMuted |
| 分类标签 | 11sp Medium，Primary-bg + Primary 色 |
| 交互 | Hover → ShadowMD + translateY(-1dp) |

优先级色标：
- 高 → Danger 红圈
- 中 → Warning 黄圈
- 低 → Border 灰圈
- 完成 → Success 绿色填充 + ✓

### 空状态

当今日没有任务时：
```
┌─────────────────────────┐
│                         │
│         🎉              │
│    今天没有待办事项       │
│  试试说"提醒我明天开会"   │
│                         │
│    ┌───────────────┐    │
│    │   ＋ 创建任务   │    │
│    └───────────────┘    │
│                         │
└─────────────────────────┘
```

### 天气主题联动

整个页面的配色跟随天气主题变化（已有实现），统计卡片和任务卡片保持 BgCard 不变。

## 后期愿景（AI 伙伴增强）

1. **情绪感知问候** — SER 检测到用户压力大时："今天辛苦了，让我帮你梳理一下"
2. **AI 主动建议** — 根据历史习惯，主动推荐任务
3. **每日总结** — 晚间自动生成今日完成情况摘要
4. **语音快捷创建** — 底部浮动麦克风按钮，随时说话创建任务
