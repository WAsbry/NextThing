# 10 — 设置页

## 定位

应用全局设置，从"我的"页进入。

## 核心功能

1. 通知设置（提醒时间、方式）
2. AI 设置（ASR 引擎选择、SER 灵敏度）
3. 数据管理（导出 / 导入 / 清除）
4. 隐私设置
5. 关于

## 视觉设计

标准设置列表页，分组卡片：

```
┌─────────────────────────┐
│  ‹    设置                │
│                         │
│  ┌───────────────────┐  │
│  │ 🔔 通知设置       › │  │  ← 通知组
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │ 🤖 AI 引擎        › │  │  ← AI 组
│  │ 🎙 ASR 引擎  端侧  │  │
│  │ 💗 SER 灵敏度  中  │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │ 💾 数据管理       › │  │  ← 数据组
│  │ 🔒 隐私设置       › │  │
│  │ ℹ️ 关于           › │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## 设计要点

与"我的"页设置列表样式一致：
- 分组卡片，BgCard + RadiusMD + ShadowSM
- 行高 52dp
- 右侧显示当前值 + 箭头
