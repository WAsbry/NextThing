# 06 — 我的页

## 定位

个人中心，管理账号、偏好设置、主题切换等功能入口。

## 核心功能

1. 用户头像 + 昵称
2. 设置入口列表
3. 主题切换（天气联动 / 手动 / 深色模式）
4. 关于应用

## 设计要点

### 用户卡片

| 元素 | 规格 |
|------|------|
| 背景 | Primary → PrimaryDark 渐变 |
| 圆角 | RadiusLG |
| 高度 | 120dp |
| 头像 | 56dp 圆形，白色边框 2dp |
| 昵称 | 18sp Bold，白色 |
| 邮箱 | 13sp Regular，白色 80% |

### 设置列表

| 元素 | 规格 |
|------|------|
| 卡片 | BgCard，RadiusMD，ShadowSM |
| 行高 | 52dp |
| 图标 | 24sp emoji |
| 标签 | 15sp Medium，TextPrimary |
| 箭头 | TextMuted |
| 分割线 | Border，1dp（行间） |

### 退出登录

| 元素 | 规格 |
|------|------|
| 按钮 | 幽灵按钮，Danger 色 |
| 字体 | 14sp Medium |
| 位置 | 列表下方 24dp |

## 子页面

### 主题设置

- 天气联动（自动跟随天气切换配色）
- 手动选择主色（色板）
- 深色模式（跟随系统 / 强制浅色 / 强制深色）

### 分类管理

- 分类列表（颜色 + 名称 + 任务数量）
- 新增分类
- 编辑分类（颜色选择器）
- 删除分类

### 视图偏好

- 默认排序方式
- 默认筛选 Tab
- 任务卡片显示密度（紧凑 / 标准 / 宽松）
- 日期格式偏好
