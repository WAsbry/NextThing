# 11 — 成就

## 定位

游戏化激励系统，通过徽章和成就鼓励用户坚持使用。

## 核心功能

1. 成就徽章列表（已解锁 / 未解锁）
2. 成就进度
3. 连续天数里程碑

## 视觉设计

```
┌─────────────────────────┐
│  ‹    成就                │
│                         │
│  已解锁 3/12              │  ← 总进度
│  ████░░░░░░              │
│                         │
│  ── 习惯养成 ─────────── │
│                         │
│  ┌───┐ ┌───┐ ┌───┐      │
│  │ 🌟 │ │ 🔥 │ │ 💎 │    │  ← 徽章网格
│  │首次 │ │连续 │ │全勤 │    │
│  │完成 │ │7天 │ │30天 │    │
│  └───┘ └───┘ └───┘      │
│                         │
│  ┌───┐ ┌───┐ ┌───┐      │
│  │ 🎯 │ │ 🏃 │ │ 📚 │    │
│  │效率 │ │健康 │ │学习 │    │
│  │达人 │ │达人 │ │达人 │    │
│  └───┘ └───┘ └───┘      │
│                         │
└─────────────────────────┘
```

## 设计要点

| 元素 | 规格 |
|------|------|
| 徽章格 | 3 列网格，间距 12dp |
| 徽章 | 80dp × 80dp，RadiusMD |
| 已解锁 | BgCard + ShadowSM + 彩色图标 |
| 未解锁 | BgInput + 灰色图标 + 锁定 |
| 进度条 | 4dp 高度，Primary 色 |
