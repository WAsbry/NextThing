# 12 — 地理围栏

## 定位

基于位置的智能提醒，到达/离开特定地点时自动触发任务提醒。

## 核心功能

1. 地图选点
2. 围栏半径设置
3. 关联任务
4. 到达/离开触发选择

## 视觉设计

```
┌─────────────────────────┐
│  ‹    地理围栏            │
│                         │
│  ┌───────────────────┐  │
│  │                   │  │
│  │    🗺 地图区域     │  │  ← 地图占位
│  │      ○ 围栏圈     │  │
│  │                   │  │
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │ 📍 地点名称       › │  │
│  │ 📏 围栏半径  500m › │  │
│  │ 🔔 触发条件  到达  › │  │
│  └───────────────────┘  │
│                         │
│  关联任务                │
│  ┌───────────────────┐  │
│  │ ☑ 去超市买菜        │  │
│  │ ☐ 取快递           │  │
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │      保存围栏       │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## 设计要点

- 地图区域占屏幕 40%
- 围栏圈用 Primary 色半透明
- 配置卡片与创建任务页一致
- 关联任务用勾选列表
