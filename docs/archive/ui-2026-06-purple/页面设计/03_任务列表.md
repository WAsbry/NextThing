# 03 — 任务列表

## 定位

任务列表页展示所有任务的全局视图，支持按分类、日期、优先级筛选和排序。是"我的任务宇宙"。

## 核心功能

1. 任务列表展示（全部 / 今天 / 近7天 / 已完成）
2. 分类筛选（横向滑动标签）
3. 搜索
4. 排序（时间 / 优先级 / 分类）
5. 批量操作（长按多选）
6. 下拉刷新

## 设计要点

### 搜索框

| 元素 | 规格 |
|------|------|
| 高度 | 44dp |
| 圆角 | RadiusFull (999dp) |
| 背景 | BgInput |
| 图标 | 🔍 18sp，TextMuted |
| placeholder | 14sp，TextMuted |
| Focus | BorderFocus + ShadowPrimary |

### 分类标签

| 元素 | 规格 |
|------|------|
| 布局 | 横向滑动 Row |
| 标签 | 胶囊形状，RadiusFull |
| 默认态 | BgInput 背景 + TextSecondary |
| 选中态 | Primary-bg + Primary 字色 |
| 间距 | 8dp |
| 高度 | 32dp |

### 日期分组头

| 元素 | 规格 |
|------|------|
| 文字 | 13sp SemiBold，TextSecondary |
| 装饰 | 文字 + 水平线填充剩余宽度 |
| 上下间距 | 12dp / 8dp |

### 任务卡片

与今日页相同的卡片样式，增加：
- 左滑操作：删除、编辑、标记完成
- 长按：进入多选模式
- 分类色标：分类颜色作为卡片左侧 3dp 竖条

### 空状态

```
        📋
   还没有任务哦
  点击下方 ＋ 创建第一个任务
```

## 筛选与排序

### 筛选 Tab（顶部）

| Tab | 筛选逻辑 |
|-----|---------|
| 全部 | 所有未完成任务 |
| 今天 | dueDate == today |
| 近7天 | dueDate in [today, today+7] |
| 已完成 | isCompleted == true |

### 排序（右上角图标点击弹出）

| 排序 | 逻辑 |
|------|------|
| 默认 | 按创建时间倒序 |
| 按时间 | 按 dueDate 升序 |
| 按优先级 | 按priority降序 |
| 按分类 | 按 category 分组 |
