# 09 — 日历

## 定位

日历视图，按月展示任务分布，快速导航到某天的任务。

## 核心功能

1. 月历视图（日期网格 + 任务数圆点）
2. 选中日期 → 显示当天任务列表
3. 左右滑动切换月份
4. 有任务的日期显示圆点标记

## 视觉设计

```
┌─────────────────────────┐
│  ‹    日历                │
│                         │
│       2025年6月           │  ← 月份标题
│  一  二  三  四  五  六  日│
│                          │
│   .   .   .  12   .   .  │  ← 圆点表示有任务
│   .   .   .   .   .   .  │
│   .  22  23   .  25   .  │  ← 选中日期高亮
│   .   .   .   .   .      │
│                         │
│  6月22日 · 周日           │  ← 选中日期
│  ┌───────────────────┐  │
│  │ ○ 跑步5公里         │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │ ○ 复习算法          │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## 设计要点

| 元素 | 规格 |
|------|------|
| 日期格 | 40dp × 40dp |
| 选中日期 | Primary 圆形背景 + 白字 |
| 今天 | Primary 色圆点 |
| 有任务 | 底部小圆点（Primary 色） |
| 任务列表 | 与今日页卡片样式一致 |
