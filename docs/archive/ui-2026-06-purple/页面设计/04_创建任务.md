# 04 — 创建任务

## 定位

创建任务页是 NextThing 的核心差异化页面。用户通过**语音说话**，AI 自动解析出任务标题、日期、时间、分类、优先级，用户确认后一键创建。

这是"语音优先"交互范式的核心体现。

## 核心功能

1. 语音输入（长按说话 → ASR 识别 → 实时显示）
2. AI 智能解析（自动提取标题、日期、时间、分类、优先级）
3. 手动编辑（键盘输入 + 手动调整配置）
4. 任务配置（日期、时间、分类、优先级、重复、地点）

## 设计要点

### 标题输入区

| 元素 | 规格 |
|------|------|
| 最小高度 | 110dp（自适应） |
| 圆角 | RadiusMD (14dp) |
| 背景 | BgCard |
| 阴影 | ShadowMD |
| Focus | BorderFocus + ShadowPrimary |
| 字体 | 16sp Medium，TextPrimary |
| placeholder | 16sp，TextMuted |
| maxLines | 4 |

### 配置卡片

| 元素 | 规格 |
|------|------|
| 卡片 | BgCard，RadiusMD，ShadowSM |
| 行高 | 48dp |
| 图标 | 32dp 圆角方块，对应颜色背景 |
| 标签 | 14sp Medium，TextPrimary |
| 值 | 13sp，TextSecondary |
| 箭头 | TextMuted |
| 分割线 | Border，1dp |
| Hover | ShadowMD |

图标颜色：
- 日期 → Primary-bg
- 时间 → Success-bg
- 分类 → Warning-bg
- 优先级 → Danger-bg
- 重复 → Primary-bg

### 底部操作栏

| 元素 | 规格 |
|------|------|
| 取消 | 60dp × 44dp 胶囊，BgCard + ShadowSM |
| 语音按钮 | weight(1f) × 44dp 胶囊，Primary-bg |
| 保存 | 68dp × 44dp 胶囊，Primary + 白字 + ShadowPrimary |
| 间距 | 10dp |

语音按钮状态：
- 默认：Primary-bg(8%) + 🎙 图标 + "长按说话"
- 模型加载：TextMuted-bg(8%) + Loading + "端侧模型加载中..."
- 录音中：Primary-bg(18%) + 红色录音点 + "松开结束" + 脉冲动画
- 按压阴影：ShadowPrimary

### AI 解析结果卡片

| 元素 | 规格 |
|------|------|
| 背景 | `linear-gradient(135deg, rgba(108,92,231,0.04), rgba(162,155,254,0.06))` |
| 边框 | 1.5dp，`rgba(108,92,231,0.15)` |
| 阴影 | ShadowMD |
| 圆角 | RadiusMD |
| 内边距 | 16dp |

徽章：✨ + "AI 解析结果"，13sp SemiBold，Primary
置信度：11sp SemiBold，Success-bg + Success 色
字段：图标 + 标签(48dp宽) + 值
按钮组：[取消(Ghost)] [继续编辑(Outline)] [直接创建(Filled)]

## 交互流程

```
用户长按麦克风
  ↓
权限检查 → 无权限 → 弹窗请求 → 用户授权 → 不自动录音
         → 有权限 → 开始 ASR 录音
  ↓
onPartial → 实时更新标题输入框
  ↓
用户松开 → onFinal → 停止录音 → 更新标题
  ↓
自动触发 parseWithAI()
  ↓
AI 解析中 → 显示 Loading
  ↓
解析成功 → 显示 AI 卡片，隐藏标题输入框
  ↓
用户选择：
  ├── 直接创建 → applyAIResultAndCreate() → 返回
  ├── 继续编辑 → applyAIResult() → 恢复输入框，填充结果
  └── 取消 → dismissAIResult() → 恢复初始态
```

## 后期愿景

1. **拍照创建** — 拍白板/截图 → OCR + AI 解析 → 批量创建
2. **情绪感知** — SER 检测到用户语气急躁时，AI 自动降低优先级，避免过度施压
3. **上下文联想** — AI 根据用户历史习惯，自动推荐分类和时间
4. **语音连续创建** — "还有..." 继续追加任务，无需退出
