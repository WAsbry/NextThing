# 创建任务页面 — 手动测试用例

## 前置条件
- 应用已安装并运行
- 已完成登录，进入今日页

## 进入创建任务页面
点击底部导航栏的 **"+"** 按钮

---

## 状态 1：空表单（按钮禁用）

**操作**：进入创建任务页面，不做任何输入

**验证**：
- [ ] 标题输入框显示占位文字"输入任务内容"
- [ ] 8 个配置卡片均显示"未设置/未选择"
- [ ] 底部胶囊条半透明（禁用态）
- [ ] "创建任务"按钮不可点击

---

## 状态 2：输入标题（按钮激活）

**操作**：在标题输入框输入"完成项目报告"

**验证**：
- [ ] 文字正常显示，无异常
- [ ] 底部胶囊条变为完全不透明（激活态）
- [ ] "创建任务"按钮可点击

---

## 状态 3：日期卡片展开

**操作**：点击「日期」配置卡片

**验证**：
- [ ] 卡片边框变紫色，显示 ▲ 图标
- [ ] 展开面板显示快捷日期选项：今天、明天、后天、下周一等
- [ ] 点击某个快捷日期后，卡片值更新
- [ ] 再次点击卡片，面板收起

---

## 状态 4：分类卡片展开

**操作**：点击「分类选择」配置卡片

**验证**：
- [ ] 展开面板显示分类标签列表（工作、生活、学习等）
- [ ] 点击某个分类，卡片值更新为该分类名
- [ ] 底部有"管理分类"选项

---

## 状态 5：重要程度展开

**操作**：点击「重要程度」配置卡片

**验证**：
- [ ] 展开面板显示四象限选项：
  - 🔥 重要紧急
  - ⭐ 重要不紧急
  - ⚡ 不重要紧急
  - 🔵 不重要不紧急
- [ ] 点击某个选项，卡片值更新

---

## 状态 6：语音录制中

**操作**：长按底部胶囊条左侧的麦克风按钮

**验证**：
- [ ] 整个胶囊条变为红色
- [ ] 麦克风位置显示波形动画
- [ ] 右侧文字变为"录音中..."或"松开结束录音"
- [ ] 松开手指后恢复紫色

**注意**：需要授予麦克风权限。首次点击会弹出系统权限弹窗，点"允许"。

---

## 状态 7：AI 解析中

**操作**：长按麦克风说话 → 说"明天下午三点提醒我开会" → 松开

**验证**：
- [ ] 标题区域消失
- [ ] 显示 loading 旋转动画
- [ ] 文字显示"AI 正在解析..."
- [ ] 底部胶囊条变为半透明禁用态

**注意**：需要端侧 AI 模型加载完成（首次启动需等待）

---

## 状态 8：AI 单条结果

**操作**：语音说一句任务，AI 返回单个结果

**验证**：
- [ ] 显示 AI 结果卡片，带紫色"AI"标签
- [ ] 卡片显示解析出的任务标题
- [ ] 显示解析出的日期、时间、提醒等标签
- [ ] 底部有两个按钮："编辑后创建" + "直接创建"
- [ ] 点击"直接创建"→ 任务创建成功，返回今日页
- [ ] 点击"编辑后创建"→ 结果填入表单，可继续编辑

---

## 状态 9：AI 多条结果

**操作**：语音说多句任务，如"完成项目报告，给张经理发邮件，预约下周会议室"

**验证**：
- [ ] 显示"AI 识别到 3 个任务"
- [ ] 每个任务前有复选框，默认勾选
- [ ] 可以取消勾选某些任务
- [ ] 底部按钮显示"创建选中 (2)"（动态数字）
- [ ] 点击"创建选中"→ 勾选的任务全部创建

---

## 状态 10：AI 解析失败

**操作**：断开网络后尝试语音输入（或 AI 服务异常时）

**验证**：
- [ ] 显示红色错误提示卡片
- [ ] 错误信息包含"AI 解析失败"相关文字
- [ ] 有"关闭"或"重试"按钮
- [ ] 关闭后回到正常表单状态

---

## 状态 11：通知策略弹窗

**操作**：点击「通知策略」配置卡片

**验证**：
- [ ] 底部弹出 ModalBottomSheet
- [ ] 显示可用通知策略列表
- [ ] 每个策略可点击选择
- [ ] 有"新建策略"和"管理"选项
- [ ] 选择后卡片值更新为策略名称

---

## 状态 12：重复频率展开

**操作**：点击「重复频次」配置卡片

**验证**：
- [ ] 展开面板显示选项列表：单次任务、每日、工作日、法定假日、自定义
- [ ] 当前选中项前有紫色圆点
- [ ] 点击选项后卡片值更新

---

## 状态 13：图片预览

**操作**：点击「任务图片」配置卡片

**验证**：
- [ ] 展开面板显示两个选项："从相册选择" + "拍照"
- [ ] 点击"从相册选择"→ 打开系统相册，选择后显示预览
- [ ] 点击"拍照"→ 打开相机（需要相机权限）
- [ ] 选择/拍照后卡片值更新为"已选择"

---

## 状态 14：地理围栏展开

**操作**：点击「地理围栏」配置卡片

**验证**：
- [ ] 展开面板显示开关按钮
- [ ] 打开开关后显示已保存的位置列表
- [ ] 可选择某个位置
- [ ] 有"添加新位置"选项

---

## 状态 15：全部配置完成

**操作**：填写所有字段 → 标题 + 日期 + 时间 + 分类 + 重要程度 + 图片 + 通知策略 + 重复 + 地理围栏

**验证**：
- [ ] 所有配置卡片显示已设置的值
- [ ] 底部胶囊条完全不透明，可点击
- [ ] 点击"创建任务"→ 任务创建成功
- [ ] 返回今日页，新任务出现在列表中

---

## 状态 16：日期选择器弹窗

**操作**：点击「日期」卡片展开后，点击"选择日期"或日历图标

**验证**：
- [ ] 弹出 Material3 日期选择器对话框
- [ ] 显示日历网格，今天高亮
- [ ] 可左右切换月份
- [ ] 选择日期后点"确定"，卡片值更新

---

## 状态 17：精确时间 iOS 滚轮

**操作**：点击「精确时间」配置卡片

**验证**：
- [ ] 展开面板显示 iOS 风格滚轮（白色背景）
- [ ] 上下滚动小时列，数字可滑动
- [ ] 上下滚动分钟列，数字可滑动
- [ ] 中间选中行有紫色边框高亮
- [ ] 上下区域有白色渐隐遮罩效果
- [ ] 冒号分隔符为紫色
- [ ] 确定按钮显示"确定 HH:MM"（动态时间）
- [ ] 点击"确定"→ 时间保存，卡片值更新
- [ ] 点击"清除"→ 时间清除，卡片恢复"未设置"

---

## 状态 18：重复频率 — 每月

**操作**：展开「重复频次」→ 点击"自定义" → 选择"每月"

**验证**：
- [ ] 显示日期选择面板（1-28/31号）
- [ ] 可点击选中多个日期
- [ ] 选中的日期为紫色圆形
- [ ] 再次点击取消选中

---

## 状态 19：麦克风权限弹窗

**操作**：首次点击麦克风 → 在系统弹窗中选择"拒绝"

**验证**：
- [ ] 弹出品牌化权限引导弹窗
- [ ] 标题："需要麦克风权限"
- [ ] 说明文字包含开启权限的步骤
- [ ] "取消"按钮（灰色）+ "去设置"按钮（紫色）
- [ ] 点击"去设置"→ 跳转系统应用设置页

---

## 状态 20：相机权限弹窗

**操作**：展开图片卡片 → 点击"拍照" → 在系统弹窗中选择"拒绝"

**验证**：
- [ ] 弹出品牌化权限引导弹窗
- [ ] 标题："需要相机权限"
- [ ] 说明文字包含开启权限的步骤
- [ ] "取消"按钮（灰色）+ "去设置"按钮（紫色）
- [ ] 点击"去设置"→ 跳转系统应用设置页

---

## 底部胶囊条（贯穿所有状态）

**验证**：
- [ ] 正常态：紫色胶囊，左侧圆形麦克风 + 分割线 + "创建任务"文字
- [ ] 录音态：整条变红色，麦克风内显示波形动画
- [ ] 禁用态：半透明
- [ ] AI 解析中：半透明，文字变"解析中..."

---

## 回归检查

| 检查项 | 预期 |
|--------|------|
| 返回按钮 | 点击左上角 ← 返回今日页 |
| 标题必填 | 空标题时创建按钮不可点击 |
| 创建成功 | 创建后自动返回今日页，任务出现在列表 |
| AI 取消 | AI 结果卡片可关闭，回到表单 |
| 配置互斥 | 同一时间只有一个配置卡片展开 |
