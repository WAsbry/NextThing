页面定位

我的页只显示“地理围栏”入口；独立页才展示概览卡。这样既保留功能存在感，也不会把个人页变成复杂设置页。

状态规则

  • 无前台定位权限：顶部状态显示“缺少权限”，优先引导授权。
  • 无后台定位权限：展示“待确认”，说明后台触发可能不稳定。
  • 无地点时：显示空状态和添加地点入口。
  • 已配置地点后：空状态替换为地点列表，展示地点名、半径、关联任务数和触发方式。
