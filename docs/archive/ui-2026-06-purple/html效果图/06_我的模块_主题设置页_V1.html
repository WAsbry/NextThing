页面定位

主题设置是独立配置页，不在“我的”首页展开。首页只显示当前状态：跟随系统、浅色、深色或跟随天气。

Compose 对齐

  • 复用现有 `ThemeSettingsScreen` 和 `ThemeSettingsViewModel`。
  • 保留天气主题自定义主色和预览逻辑。
  • 编码阶段主要做视觉升级，不改变主题持久化逻辑。
