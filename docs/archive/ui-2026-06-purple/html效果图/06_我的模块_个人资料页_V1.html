页面定位

个人资料页只回答“我是谁”。它承接头像、昵称、成就入口和登录状态，不承接账号绑定、任务统计和系统能力配置。

首屏层级

第一层：身份卡，展示头像、昵称、成就解锁数、成就入口和使用天数。
第二层：资料编辑，仅保留头像更换和昵称编辑。
第三层：账号状态，仅展示“已登录”。
第四层：账号操作，仅保留退出登录，使用浅红背景和红色文字。

删除项

本页不再展示手机号、微信、QQ，也不展示额外账号类型。NextThing 当前只有一个账号语义，登录状态足够表达。

编码映射

UserInfoScreen：重组为身份头 + 资料编辑 + 登录状态 + 账号操作。
UserInfoViewModel：保留头像、昵称、成就入口和退出登录能力；移除非核心资料项、账号绑定展示入口和高敏感账号操作。
图片选择器：只在个人资料页点击头像时触发。
昵称弹窗：点击昵称行弹出输入框，左侧取消，右侧确认。
