# NextThing UI 设计总览

> 已归档：本文件和同目录原型主要记录 2026 年 6 月的紫色主题探索。它们不代表当前实现；当前蓝白主题与天气动态配色请参阅 `docs/current/UI_BASELINE.md` 和源码中的 `presentation/theme/Color.kt`、`Theme.kt`。

## 设计理念

NextThing 是一个**端侧多模态 AI 伙伴**，UI 设计需要传达三个核心感受：

1. **智能感** — AI 不是冷冰冰的工具，而是懂你的伙伴
2. **高级感** — 精致的拟态设计，App Store 上架品质
3. **温度感** — 柔和的配色、圆润的形状、有生命力的动效

## 设计对标

| 对标应用 | 学习点 |
|---------|--------|
| Things 3 | 极简留白、动效流畅、圆角卡片 |
| TickTick | 功能密度高但不杂乱、信息层级清晰 |
| Notion | 块状布局、优雅排版 |
| Apple Reminders | 系统级视觉一致性 |

## Design Token

### 1. 主色 — 清爽蓝

默认浅色主题采用蓝白视觉。应用自有组件通过 `LocalAppColors` 使用 `#0A84FF`，Material 3 组件的基础色板使用 `#4FC3F7` / `#29B6F6`。两套蓝色目前并存，新增页面应优先读取主题 Token，避免继续硬编码颜色。

```
App Primary:        #0A84FF  (应用级主操作)
App Primary Dark:   #006EDB  (按压态/深色层级)
Material Primary:   #4FC3F7  (Material 组件基础蓝)
Material Secondary: #29B6F6  (Material 次级蓝)
```

### 2. 语义色

```
Success:  #4CAF50  (完成、通过)
Warning:  #FF9800  (提醒、中优先级)
Danger:   #F44336  (错误、高优先级、删除)
Purple:   #AB47BC  (局部统计/AI 语义强调)
```

### 3. 背景色

```
BgPage:       #F7F8FC  (页面底色 — 极浅蓝灰)
BgCard:       #FFFFFF  (卡片底色 — 纯白)
BgInput:      #F1F3F8  (输入框底色 — 浅灰)
BgInputFocus: 由当前主题主色以低透明度生成
```

### 4. 文字色

```
TextPrimary:   #2D3436  (主文字 — 深墨)
TextSecondary: #636E72  (副文字 — 灰)
TextMuted:     #B2BEC3  (弱文字 — 浅灰)
TextOnPrimary: #FFFFFF  (主色上文字)
```

### 5. 边框

```
Border:        #E8ECF1  (默认边框)
BorderFocus:   当前主题 Primary
```

### 6. 阴影 — 拟态系统

```
ShadowXS:  0 1px 2px rgba(0,0,0,0.03)                    (微阴影 — 分隔)
ShadowSM:  0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06)  (卡片默认)
ShadowMD:  0 4px 12px rgba(0,0,0,0.06), 0 2px 4px rgba(0,0,0,0.04) (卡片 hover)
ShadowLG:  0 8px 24px rgba(0,0,0,0.08), 0 4px 8px rgba(0,0,0,0.04) (弹窗、模态)
ShadowPrimary: 由当前主题 Primary 生成低透明度阴影（CTA）
```

### 7. 圆角

```
RadiusSM:   10dp  (小组件、标签)
RadiusMD:   14dp  (卡片、输入框)
RadiusLG:   20dp  (大卡片、弹窗)
RadiusFull: 999dp (胶囊按钮、头像)
```

### 8. 间距

```
SpaceXS:  4dp
SpaceSM:  8dp
SpaceMD:  16dp
SpaceLG:  24dp
SpaceXL:  32dp
```

### 9. 字体

```
FontTitle:    24sp / Bold     (页面标题)
FontSubtitle: 17sp / SemiBold (导航标题)
FontBody:     15sp / Regular  (正文)
FontCaption:  13sp / Regular  (说明文字)
FontMicro:    11sp / Medium   (标签、角标)
```

## 组件规范

### 按钮

| 类型 | 样式 | 使用场景 |
|------|------|---------|
| CTA 按钮 | 主色填充 + 白字 + ShadowPrimary | 主操作（保存、确认） |
| 轮廓按钮 | 透明 + 主色边框 + 主色字 | 次操作（继续编辑） |
| 幽灵按钮 | 透明 + 灰色字 | 取消操作 |
| 胶囊按钮 | 圆角 999dp + 拟态阴影 | 底部栏（取消、保存、语音） |

### 卡片

- 圆角 14dp，白色背景，ShadowSM
- Hover → ShadowMD + translateY(-1dp)
- 内容 padding 16dp
- 卡片间距 10dp

### 输入框

- 圆角 14dp，BgInput 背景
- Focus → BorderFocus + ShadowPrimary
- 高度最小 48dp，多行输入自适应

### AI 相关组件

- AI 页面允许使用 `#7057F5` / `#B06DFF` 紫色渐变，与全局蓝色形成语义区隔
- AI 卡片、输入焦点和主要 CTA 可使用紫色，但不应扩散为普通页面主色
- AI 徽章：紫色 + ✨ 图标
- 置信度标签：绿色背景 + 百分比

## 天气主题

保留现有天气联动主题体系，每个天气主题替换以下 Token：
- Primary / PrimaryDark
- BgPrimary / BgSecondary / Border

天气主题覆盖 `Primary / PrimaryDark / BgPrimary / BgSecondary / Border`。晴天偏暖杏黄，阴天偏蓝灰，多云和雨天偏浅蓝，雷雨偏丁香紫，雪天偏冰青，雾天偏暖灰，风天偏薄荷青。AI 与个人中心仍可使用独立紫色强调，不受天气主色约束。

## 当前颜色使用边界

| 场景 | 推荐颜色来源 |
|------|--------------|
| 普通页面、导航、主按钮 | `LocalAppColors.current.primary` / `MaterialTheme.colorScheme` |
| 页面和卡片背景 | `bgPrimary` / `bgCard` / `bgSecondary` |
| 成功、提醒、危险 | `success` / `warning` / `danger` |
| AI、个人中心的专属视觉 | 页面内紫色 Token；仅限语义化使用 |
| 统计图表 | 主题色 + 语义色组合，保证不同指标可区分 |
| 天气模式 | `weatherAppColors(condition)`，可叠加用户自定义主色 |

当前代码仍有少量页面级硬编码紫色，这是现有视觉语义的一部分，同时也是后续设计 Token 收敛的维护点。
