# NextThing 任务/统计一级页断点（2026-08-15）

## 本次完成

- 仅修改底部导航“任务”一级页和“统计”一级页；未修改首页、创建页、底部导航及统计二级页。
- 任务页职责固定为任务搜索、状态筛选、周/月浏览和任务处理。
- 统计页职责固定为执行结果概览、风险指标、完成趋势与专项分析入口。
- 统计页三个摘要指标取消任务列表弹窗入口，避免与任务页职责重叠。
- 两页统一采用 10dp 页面边距、8dp 小圆角、白底细描边、蓝色主色和局部语义状态色。
- 任务搜索中的 Emoji AI 图标改为文字操作；搜索空状态取消大型装饰图。
- 统计专项分析由彩色 2×2 卡片改为紧凑描边入口行，默认页移除紫色视觉强调。
- 任务搜索进入编辑态时显式把输入选区恢复到关键词末尾，同时保留用户手动移动光标的能力。
- 任务搜索的 AI 操作收口为“智能筛选”：提供加载、成功、无结果、失败与重试反馈；失败保留普通搜索结果，退出智能筛选后恢复本地关键词结果，修改关键词或状态筛选会终止旧结果。
- 智能筛选请求期间收起键盘并进入独立内容加载态：保留顶部搜索栏，隐藏周/月切换、状态筛选和普通结果，加载动画与查询说明在剩余内容区域居中展示。
- 周视图与月视图共用顶部中央时间导航：当前范围分别显示“本周”或“本月”，左右箭头切换周/月，点击中间标签回到当前周/月；月历内容区不再重复展示月份导航。
