# NextThing 当前 UI 基线

> 基线来源：`app/src/main/java/com/nextthing/app/presentation/theme/Color.kt`、`Theme.kt` 及当前 Compose 页面。日期：2026-08-15。

## 默认视觉

### 一级页面通用规则（2026-08-15）

- 页面背景采用 `#F7F8FC`，内容模块以白底组织；一级页面左右外边距优先使用 10dp。
- 普通卡片、筛选器和弹出菜单使用 8dp 小圆角与 0.5–1dp 细描边；仅底部主操作等明确主行动允许使用胶囊形。
- 蓝色 `#0A84FF` 用于选中态、核心指标和主操作；绿、橙、红只承担完成、风险、逾期等局部状态语义。
- 普通信息卡不依赖重阴影；图标使用项目矢量/线性图标，不以 Emoji 充当功能图标或空状态主体。
- 任务一级页负责查找、筛选、浏览和处理任务；统计一级页负责结果概览、趋势与分析导航，不在统计指标中重复提供任务处理列表。

### 任务与统计一级页（2026-08-15 断点）

- 任务页保留周视图、月视图、状态筛选和搜索；筛选控件、下拉菜单、月历及日期详情统一为小圆角细描边，普通空状态不展示 Emoji 或大型装饰图。
- 统计页时间范围选择统一为描边分段控件；完成率是首要结果，待办/逾期/重要紧急为不可点击的统计摘要；完成趋势用于解释变化，专项分析使用创建页式紧凑入口行。
- 统计默认页不得使用紫色作为模块主色；AI 周报在一级页仅作为普通分析入口，不以紫色卡片争夺主视觉。

### 首页当前位置（2026-08-12 断点）

- 首页顶部位置胶囊只展示区域级摘要（优先“区 · 街道/园区”），不直接展示完整精确地址。
- 点击位置胶囊打开当前位置详情卡：完整地址为正文，坐标、精度和更新时间为辅助属性；采用任务详情/编辑态的信息卡语言（8dp 圆角、1dp 主题描边、40dp 高主按钮、文字次操作）。
- 定位刷新失败在当前位置详情卡内使用紧凑状态条反馈；不得自动叠加旧的长篇位置帮助弹窗。

- 风格：蓝白现代卡片式移动界面，使用浅蓝灰背景、白色卡片与清晰的信息层级。
- 应用组件主色：`#0A84FF`；深色层级：`#006EDB`。
- Material 3 基础蓝：`#4FC3F7`；次级蓝：`#29B6F6`。
- 背景：`#F7F8FC`、`#FFFFFF`、`#F1F3F8`。
- 正文：`#2D3436`；次级文字：`#636E72`；边框：`#E8ECF1`。

## 主题模式

支持浅色、深色、跟随系统和跟随天气。天气主题会根据晴、阴、多云、雨、雷雨、雪、雾、风等状态覆盖主色与背景，且允许用户为不同天气设置自定义主色。

## 紫色的使用边界

紫色不是全局主色。它仅用于 AI 配置、个人中心、信息 Toast、部分统计指标、雷雨主题和部分滑动操作等局部语义强调。普通页面、导航和主操作应优先读取 `LocalAppColors` 或 `MaterialTheme.colorScheme`，避免新增硬编码颜色。
