# NextThing 当前项目状态

> 基线日期：2026-08-15。本文描述当前工作区实现，不代表已发布版本；发布结论必须以当次完整构建、自动化测试和真机回归为准。

## 当前定位

NextThing 是面向个人用户的 Android 智能任务管理应用，采用 Kotlin、Jetpack Compose、Material 3、Clean Architecture 与 MVVM。当前工作区处于大规模整合阶段，功能实现领先于最近 Git 提交，仍有大量未提交改动。

## 已实现并持续整合的能力

- 任务管理：状态流转、四象限、重复任务、子任务、标签、附件和 CSV/XLSX/Markdown 导出。
- AI：自然语言任务解析、AI 助手、AI 配置和后端 AI 调用链路。
- 语音：CPU Paraformer 流式识别与 Qualcomm QNN HTP SenseVoice 二阶段端侧 ASR；完整体验需要独立模型与 native runtime 资源包。
- 位置与提醒：高德选点、地理围栏、后台 Worker、任务闹钟与通知策略。
- 数据能力：同步、Token 自动刷新、Keystore 敏感信息加密、Room v13 显式迁移、统计与天气。

## 最近开发断点

- 2026-08-15：底部导航“任务”和“统计”两个一级页完成职责与视觉收口。任务页负责搜索、状态筛选、周/月浏览和任务处理；统计页只负责时间范围内的执行结果、风险指标、完成趋势和专项分析入口，统计指标不再打开任务处理列表。两个页面统一采用默认蓝色主色、10dp 页面边距、8dp 小圆角、白底细描边和克制状态色；首页、创建页、底部导航及统计二级页未纳入本次修改。
- 2026-08-12：地理围栏“新建地点”流程已重构为两页。新建页负责地点命名、默认“使用当前位置”、位置摘要和 Room 保存；地图页负责当前位置、POI/地址搜索、地图拖动选点和逆地理编码。地图确认仅回填草稿，点击“保存地点”后才写入数据库；保存成功后返回并显示成功提示。
- 2026-08-12：当前位置链路已收口为高德定位唯一来源，移除了 Google 定位回退；Debug 包已确认注入本地 `AMAP_API_KEY`，但旧 Key 的真机有效性仍待用户验证。首页顶部只展示区域摘要，点击后在当前位置详情卡展示完整地址、坐标、精度、更新时间与刷新操作；刷新失败在同一卡片内提示，不再弹出旧的“位置获取帮助”二级弹窗。
